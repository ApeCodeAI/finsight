# modules/decision — 决策类（占位）

下个阶段的内容：

- `journal/` 决策日志：每次重要操作（加仓/换仓/清仓）的当时想法
- `goal/` 投资目标：净值目标、配置目标、年化目标
- `review/` 复盘：周/月/季度对比
- `braindump-bridge/` 通过 `braindump_id` 关联 Braindump 笔记，双向跳转

**为什么现在是占位**：FinSight 的第一阶段聚焦在「看清数据」—— 先把 view 跑起来，把投资全貌摆在桌面上，口径稳了再上决策能力。journal / goal / review 作为后续阶段加入。
